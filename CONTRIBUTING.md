# Contributing

Thanks for helping investigate an Exynos 9820 EDK2 port.

## Before submitting

- Explain which exact model/variant your change targets.
- Link the primary source for hardware-specific claims.
- Pin external source revisions when referring to code.
- Mark facts as verified, inferred or unknown.
- Keep Qualcomm-specific Renegade code clearly separated from Exynos-specific work.
- Do not submit guessed register maps, memory addresses, partition offsets or boot arguments.
- Do not describe a change as bootable without repeatable hardware evidence.

## Pull request expectations

Include the problem, proposed change, evidence, validation performed, and remaining limitations. For code, include reproducible build/test commands and logs. Never include private device identifiers, account credentials, API keys or personal data in logs.

## Scope

This repository is a research-stage UEFI feasibility port. Contributions must not imply official Renegade Project endorsement or claim Windows compatibility before the required firmware and drivers exist.
